# Threshold (working name)

College and branch decision intelligence for JEE aspirants in India. It uses official JoSAA cutoffs and keeps admission bands, quality and suitability separate.

**Status: working prototype, not the complete MVP.** It covers student profile, JoSAA eligibility, college discovery, comparison, explainable recommendations, a preference list, a cost calculator and a parent report, using 132,982 real cutoff records from 2021-2026. Sourced placement data exists for 59 institutes (institute-wide and self-reported), with branch-level figures for 4 and fees for 6. Faculty and curriculum show "Data not available", and quality scores are withheld. There are no accounts or admin yet, and the public site is read-only. See [docs/PRODUCT_REQUIREMENTS.md](docs/PRODUCT_REQUIREMENTS.md).
