# Importing placement and fee records

```bash
cd backend
.venv/bin/python -m ingest.import_records placements ../data/import/your_file.csv
.venv/bin/python -m ingest.import_records fees ../data/import/your_file.csv --commit
```

Run without `--commit` first. That checks everything and writes nothing. A file is accepted or rejected as a whole.

Start from the headers in `templates/`.

## Rules
- **Source:** `source_key` (from `data/registry/sources.yaml`), `source_title`, `source_url`, and `source_file`, a path from the project root to your saved copy.
- **Status:** `official`, `verified`, `secondary_unverified`, `manual_unverified` or `outdated`. Use `official` for a copy from the publisher, even though the figures may be self-reported. Use `verified` only after someone checks the figures against the document. Test fixtures are rejected.
- **Placements:** `scope` is `institution` or `programme`. Never enter an institute figure as a programme record. `reporting_definition` is `nirf_graduation_outcomes` (Engineering submissions), `nirf_graduation_outcomes_overall` or `institute_placement_report`, and these are never compared with each other. `cohort_label` says who is covered.
- **Salaries:** full rupees a year. Enter the median where one is published.
- **Fees:** `seat_type_group` says who the amounts apply to. Enter a yearly amount only if the document says the charge repeats. Otherwise use `payable_at_admission_inr` and explain in `notes`.

A changed value for an existing record is reported as a conflict and isn't overwritten. To correct a record, publish the correction as a new source document.

Also accepted: `sectors` and `recruiters`, using the templates. Branch rows use `programme_name`, which must match the JoSAA name exactly, and `base_label` must say who the base group is.

## Files here
- `placements_branch_reports.csv`, `placement_sectors.csv`, `placement_recruiters.csv`: transcribed by hand from institute reports.
- `placements_nirf.csv`: generated by `ingest.nirf_fetch`, which applies the automatic checks. New documents are added with `ingest.nirf_discover` and `ingest.nirf_verify`.
- `nirf_review.json`: documents that failed a check.
- `placements_nirf_report.json`: what happened for each institute.
- `fees_official.csv`: transcribed by hand from institute circulars.
